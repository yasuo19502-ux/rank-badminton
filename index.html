☁️ Đồng Bộ Đám Mây (Supabase)

Kết nối Supabase Cloud để tự động đồng bộ kết quả, bảng xếp hạng và điểm danh tức thì giữa tất cả các máy trong CLB.

💾 Dữ Liệu & Sao Lưu (JSON)

Tải file dữ liệu JSON về máy hoặc nhập dữ liệu từ máy khác vào.

Sao Lưu & Đồng Bộ Dữ Liệu

Toàn bộ dữ liệu CLB Thái Thịnh (Thành viên, Điểm Elo, Lịch sử trận, Ảnh đại diện) được lưu an toàn trên máy bạn. Bạn có thể tải file JSON về máy để chuyển sang điện thoại khác.

☁️ Kết Nối Supabase Cloud

Kết nối Supabase để toàn bộ 20 anh chị em trong CLB xem chung một bảng xếp hạng, tự động đồng bộ thời gian thực (Realtime) khi mở trên điện thoại.

💡 Mẹo: Bạn chỉ cần copy nội dung file supabase_schema.sql và dán vào SQL Editor trên Supabase để tạo bảng trong 10 giây!
